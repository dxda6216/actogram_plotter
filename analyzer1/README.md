# Actogram Phase Analyzer – web app

`index.html` is a single, self-contained file. Open it in any modern browser
(Chrome, Edge, Firefox, Safari); no installation or internet connection is needed.
To put it online, upload `index.html` to any static host (for example GitHub Pages).

Settings are remembered in the browser. "Save settings and data…" writes a .json file
that also opens in the desktop app. Results download as CSV; the actogram as SVG or PNG.
